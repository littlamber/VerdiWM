# Ctrl-World Source-Grounded Research Loop v2

This package converts bounded arXiv and GitHub metadata into strict
source-to-target transfer assessments. It may replay a previously frozen
source bundle when the network is unavailable. Only transferable optimization
mechanisms with complete Ctrl-World capabilities receive materialization work
orders. Diagnostics, research substrates, incompatible methods, and capability
gaps are retained as knowledge-only records.

The entrypoint never mutates model source, starts a GPU process, or promotes a
result. Materialization, screen, independent confirmation, and the frozen
verifier remain separate authority boundaries.

Run:

```bash
python experiments/ctrl_world_research_loop_v2/research_intake.py --help
```
