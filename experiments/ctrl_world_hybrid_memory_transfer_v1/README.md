# Ctrl-World Hybrid Memory Transfer v1

This package materializes the two source-grounded components admitted from the
Hybrid Memory source: bounded latent-memory token compression and explicit
spatiotemporal relevance retrieval. The plugin writes only an isolated
Ctrl-World adapter module, focused tests, and a method descriptor.

It does not claim exact HyDRA reproduction, hidden-subject tracking, or
HM-World dataset transfer. The transfer is admissible only when both preserved
components map to code with zero declared compromises. GPU execution remains a
separate screen, confirmation, and frozen-verifier ladder.

The resumable campaign runner binds the evaluator dataset name into its input
lock. For trained candidates it derives that name from the immutable training
receipt; `--dataset-name` is an explicit override for candidates without a
training data receipt. Path-like names are rejected before GPU launch.
