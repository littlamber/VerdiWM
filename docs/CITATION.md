# 软件与方法引用

软件引用信息由根目录 `CITATION.cff` 提供。复现实验时请记录实际 release
版本或 commit SHA，并同时记录模型、数据、协议与评估器版本。

方法稿题目为 **VERDI: Verified Contradictions for Continual World-Model
Optimization**。本仓库的方法映射基于该稿的 Characterize → Retrieve →
Validate → Accumulate 四阶段闭环。

当前可核对材料是匿名稿；仓库尚未提供经作者确认的公开论文链接、正式作者
列表或 DOI。本文件不推断作者身份，也不把审稿状态写成正式发表信息。
正式公开引用就绪后，由维护者补充链接、作者与 BibTeX，并同步 CITATION.cff。
软件许可证不自动授予论文、模型权重或数据的再分发权。
