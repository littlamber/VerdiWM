# Python 支持与安全迁移

1.0.4rc1 将控制面最低支持线迁移至 CPython 3.12（Linux/WSL2），声明范围为
`>=3.12,<3.13`。3.10 已到生命周期末期；本轮 Pillow 安全修复版本要求至少
Python 3.11，因此不能继续用旧 3.10 锁文件发布新候选。

控制面与模型运行时独立：控制面使用 Python 3.12，外部模型仍通过
`--runtime-python` 指向它自己的解释器，不要求在同一环境安装 Torch。
迁移时重新创建控制面虚拟环境，再运行 `uv sync --locked --group dev`。
建议安装当前 3.12 安全补丁版本；具体验证的解释器补丁版本记录在验证报告中。

发布门禁要求新的锁文件可离线 frozen 同步、全部 CPU 测试通过、wheel 在仓库外
安装验证通过，并验证从 sdist 重建一致。新安全依赖可先从官方索引准备缓存，
缓存完整后才能声明离线可复现。其他 Python 版本未经验证，不通过放宽版本范围
自动声明支持。完整结果以本候选实际生成的验证报告为准。
