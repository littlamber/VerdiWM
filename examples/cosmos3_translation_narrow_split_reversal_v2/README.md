# Cosmos3 Directional Probe Held-Out Settlement

This bundle compares the same frozen directional probe on dev and accept. The locality residuals are `0.1032` and `2.4468`. The normalized Jacobian alignment error is `1.9998` against the frozen `0.5000` threshold. The final settlement is therefore `settled_abstained`.
